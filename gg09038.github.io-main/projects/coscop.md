# 藥妝品廣告詞違規檢測系統

> **一句話摘要**：將法規與違規案例整理成可維護的語意/規則資料，結合句法結構分析、API 與圖形化介面，自動檢查藥妝品廣告文案。

## Method

- 整理法規與歷史案例，建立可維護的規則與語意資料。
- 進行句法樹剖析與詞性結構化建模。
- 開發 Open API，讓其他服務可呼叫違規檢測功能。
- 建立網頁展示介面，呈現輸入文案與檢測結果。

## Results

使用隨機爬蟲資料測試 50 筆，整體成功率達九成以上，並完成可操作的系統與圖形化展示介面。
